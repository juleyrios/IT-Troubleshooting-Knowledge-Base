# No Internet Connection

## Problem

The computer is connected to a network but cannot access the internet.

## Possible Causes

* Router or modem issue
* Network adapter problem
* Incorrect IP configuration
* DNS issue
* Network outage

## Troubleshooting Steps

1. Check the Ethernet or Wi-Fi connection.
2. Restart the router and computer.
3. Check the network connection status.
4. Verify the computer has a valid IP address.
5. Test connectivity using `ping`.
6. Test another website or device.
7. Check DNS configuration if basic connectivity works but websites do not load.

## Resolution

Identify whether the issue is with the device, local network, DNS, or internet service and apply the appropriate fix.
