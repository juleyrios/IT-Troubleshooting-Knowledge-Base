# Computer Overheating

## Problem

The computer becomes unusually hot, slows down, shuts down, or the fans run constantly.

## Possible Causes

* Dust buildup
* Blocked air vents
* High CPU usage
* Failing or inadequate cooling
* Poor airflow

## Troubleshooting Steps

1. Check that the computer's air vents are not blocked.
2. Clean dust from the vents and fans.
3. Check CPU usage using the operating system's task manager.
4. Close unnecessary applications.
5. Make sure the computer has adequate airflow.
6. Monitor temperatures after cleaning and reducing system load.

## Resolution

Confirm that temperatures return to normal and that the computer operates without unexpected shutdowns.
